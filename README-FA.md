# Sahand ERP — Correspondence integration package

این بسته بدون PS1 تهیه شده است. فایل‌های این بسته با اسنپ‌شات پروژه ارسالی در ۱۸ آبان ۱۴۰۵ ساخته شده‌اند؛ **اگر بعد از آن schema یا erp-shell تغییر کرده، آن دو فایل را بدون مقایسه جایگزین نکنید.**

## نصب
۱. قبل از تغییرات از دیتابیس و پوشه پروژه نسخه پشتیبان تهیه کنید.
۲. فایل‌ها را با حفظ ساختار پوشه‌ها به ریشه پروژه منتقل کنید. فایل `prisma/schema.prisma` شامل تمام schema قدیمی اسنپ‌شات و سه مدل جدید نامه‌نگاری است؛ اگر schema فعلی تغییر کرده، ابتدا تغییرات جدید را با آن ادغام کنید.
۳. دستورات را از ریشه پروژه اجرا کنید:

```
npx prisma validate
npx prisma migrate dev --name add_correspondence
npx prisma generate
npx tsx --test tests/correspondence-policy.test.ts tests/attendance-hr-edit-window.test.ts
npx tsc --noEmit
```

**اگر Prisma درخواست reset داد، تأیید نکنید.** هیچ فایل نصب ps1 وجود ندارد.

## وضعیت و محدودیت‌ها
- ارسال و ارجاع نامه‌ها در یک تراکنش دیتابیس انجام می‌شود؛ سهمیه فوری با شمارنده اتمیک کنترل می‌شود.
- مشاهده متن و تاریخچه فقط برای فرستنده و مسئولیت‌های درگیر در گردش است.
- لیست کارتابل شامل نامه‌های قبلاً بررسی‌شده هم هست.
- این بسته جایگزین اصلاح جامع نقش‌ها، سیستم حضور و غیاب آفلاین، یا آزمون end-to-end نیست.
- تست TypeScript و Migration باید در پروژه اصلی اجرا شود؛ این محیط به دیتابیس محلی شما متصل نیست.
