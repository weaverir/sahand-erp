# بسته دستی نامه‌نگاری Sahand ERP (بدون PowerShell installer)

این بسته عمداً هیچ فایل PS1 ندارد. توجه: این نسخه هنوز برای نصب نهایی عملیاتی تأیید نشده و قبل از Migration باید اشکالات شناخته‌شده آن اصلاح شوند.

## مسیر فایل‌ها
فایل‌های این بسته را با حفظ ساختار پوشه‌ها در ریشه پروژه `C:\Users\Ehsan\Desktop\sahand` کپی کنید. فایل‌های جدید هستند و نباید فایل‌های موجود را بازنویسی کنند، به‌جز مسیرهایی که از قبل وجود دارند؛ در آن حالت ابتدا نسخه پشتیبان بگیرید.

## Schema
محتوای `prisma-schema-addition.txt` فقط بخش افزوده‌شده به انتهای `prisma/schema.prisma` در Snapshot ارسالی است. آن را فعلاً به Schema اضافه نکنید؛ ابتدا باید بررسی و اصلاحات سرویس و UI انجام شود.

## هشدار مهم
این بسته یک پیش‌نویس توسعه است، نه نسخه آماده تولید. پیش از نصب دیتابیس باید موارد زیر اصلاح شوند:
- کنترل مجوز اختصاصی نامه‌نگاری در تمام APIها.
- اصلاح UI تا تصمیم‌گیرنده از مسئولیت‌های خودش انتخاب شود، نه مسئولیت فرستنده.
- نمایش متن کامل نامه و تاریخچه فقط برای افراد مجاز.
- کنترل quota فوری به‌صورت اتمیک و بررسی رفتار تراکنش Serializable در PostgreSQL.
- ثبت مالکیت و دسترسی تاریخچه و جلوگیری از افشای اطلاعات به کاربران غیرمرتبط.

تا زمان رفع موارد بالا Migration اجرا نکنید.
